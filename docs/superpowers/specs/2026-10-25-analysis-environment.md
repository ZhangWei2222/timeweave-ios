# AI 分析服务环境开关

用户已要求方案后直接实现，不再逐项确认。

## 目标与范围

- AI 分析页提供“服务设置”，选择本地或远端，保存立即生效、跨重启保留，不自动回退。
- 默认本地 `http://127.0.0.1:8787`；远端预填 `https://api.super-vivian.top`，预填不代表已经可达。
- 两个地址分别保存；地址只接受 origin（允许末尾 `/`），禁止用户信息、query、fragment、子路径、无效端口。
- 表单修改远端地址立即清空令牌草稿；保存只提交当前选中环境，另一边保留上次成功保存的配置，不让隐藏草稿影响当前环境。
- 远端必须 HTTPS。本地 HTTP 限 localhost、回环、RFC1918 IPv4、`.local`；HTTPS 本地同样限这些主机。真机需要 Mac 局域网地址及服务监听/防火墙许可，手机 localhost 不代表 Mac。
- 远端令牌 32–256 个可见 ASCII 字符，只存 Keychain，按规范化远端 origin 隔离，不写入偏好、源码或日志。空白输入表示保留原令牌；提供显式删除。
- 保存失败不切换环境，不覆盖有效偏好。保存远端时必须有该地址的令牌。请求创建时再次读取令牌，Keychain 出错必须显式失败。
- 本地请求不带远端令牌；远端请求使用 Bearer；所有 HTTP 重定向拒绝，避免 POST 数据/令牌转交其他地址。
- 切换地址、环境、令牌后取消在途请求并清空旧结果/错误，旧任务晚返回不能覆盖新环境。
- 页上显示当前环境和实际地址；隐私文案区分 Mac 本地和远端日志，不误报远端“本机服务未启动”。
- iOS 16+、Swift 6，无新第三方依赖、不全局放宽 ATS、不在手机中嵌入云账号 AK。
- 不改变云端入口、备案、安全组、DNS；真实手机远端可达性仍需安全通道。这次交付开关，不宣称公网已打通。
- 保留现有未提交 Xcode 签名设置；只提交本功能文件/工程引用。按仓库规则验证后本地合回 main，不 push。

## 验收

偏好重载与环境隔离、坏地址/令牌、Keychain 失败不提交、本地无鉴权/远端鉴权、重定向不跟随、切换时竞争、UI 保存与重启持久化；全套 Swift 测试与双 SDK 编译。
